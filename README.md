# Quant Pro

- [quant-macros.js](quant-macros.js) — Макроси реалізовані на основі клієнтської частини сервера.
- [quant-tyre-speed.js](quant-tyre-speed.js) — Зниження максимальної швидкості авто залежно від кількості пробитих шин. Реалізовано на основі клієнтської частини сервера.
- [quant-interaction-tap.js](quant-interaction-tap.js) — Взаємодія одним натисканням E та підбір предмета під кружечком. Потребує підключення до системи предметів сервера.
